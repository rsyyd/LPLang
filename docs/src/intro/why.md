# Why LPLang?

LPLang is a pragmatic programming language designed for developers who want:

- **Familiar syntax** — Python-like with Rust-style types
- **No GC pauses** — ARC + cycle detector for deterministic memory
- **Structured concurrency** — Nurseries instead of goroutines
- **Gradual typing** — Types when you want them, dynamic when you don't
- **Batteries included** — HTTP, JSON, crypto in stdlib
