# Expressions

- Literals
- Variables: `x`
- Function calls: `add(1, 2)`
- Method calls: `vec.push(1)`
- Field access: `user.name`
- Index access: `vec[0]`
- Binary ops: `a + b`
- Unary ops: `-x`, `!flag`
- Cast: `x as i32`
- If: `if cond { a } else { b }`
- Match: `match x { 0 => a, _ => b }`
- Blocks: `{ let x = 1; x + 1 }`
