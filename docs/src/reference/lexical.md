# Lexical Structure

## Keywords
`fn`, `let`, `mut`, `const`, `struct`, `enum`, `trait`, `impl`, `use`, `mod`, `pub`, `async`, `await`, `return`, `if`, `else`, `match`, `for`, `while`, `loop`, `break`, `continue`, `nursery`, `spawn`, `unsafe`, `comptime`, `type`, `as`, `is`, `in`, `extern`, `true`, `false`

## Operators
`+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `<=`, `>`, `>=`, `&&`, `||`, `!`, `=`, `+=`, `-=`, `*=`, `/=`, `.`, `..`, `...`, `,`, `:`, `::`, `;`, `->`, `=>`, `|`, `?`

## Literals
- Integers: `42`, `1_000_000`
- Floats: `3.14`, `1.5e-10`
- Strings: `"hello"`, `"line1\nline2"`
- Chars: `'a'`, `'\n'`
- Booleans: `true`, `false`
