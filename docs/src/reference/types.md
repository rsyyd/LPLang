# Types

## Primitives
- `bool`
- Signed: `i8`, `i16`, `i32`, `i64`, `i128`, `isize`
- Unsigned: `u8`, `u16`, `u32`, `u64`, `u128`, `usize`
- Floats: `f32`, `f64`
- Text: `char`, `String`
- Never: `!`

## Compound
- Tuples: `(i32, String)`
- Arrays: `[i32; 10]`
- References: `&T`, `&mut T`
- Functions: `fn(i32) -> String`
